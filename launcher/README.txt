CODEX DECK LAUNCHER

1. Install Node.js 20 or newer.
2. Double-click "Start Codex Deck.cmd" instead of launching Codex normally.
3. Keep that Codex session open while using the Stream Deck plugin.

The launcher closes existing Codex processes, starts the installed Codex Windows
app with a loopback-only Chrome DevTools port, and enables the Codex Micro UI for
that session. It does not patch the Codex installation or upload any data.

This is an unofficial compatibility bridge and may need an update after a Codex
desktop release.
